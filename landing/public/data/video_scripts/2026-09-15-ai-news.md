# Story 1: Ambient @ EgoLongQA 2026

# Story 2: Ambient @ EgoProactive 2026
### Paper
[curious] Same team, different track. EgoProactive asks a wearable assistant one brutal question every eight seconds: should I speak up, or stay silent?

### Architecture
[confident] Their fix is reformulating intervention as visually grounded supervision — the model learns when to act from the video itself, not just labels. First in the large-model division, second under 2B.

# Story 3: Studying Without a Syllabus
### Paper
[skeptical] Here's the uncomfortable truth: most agent adaptation needs task examples or eval feedback to know what to build. This paper asks — what if you get neither?

### Architecture
[curious] They preprocess an environment task-agnostically, constructing reusable indices, scripts, and procedural guidance before the agent ever sees a task. No trajectories, no reward signal, no syllabus.

### Release Horizon
[confident] It's a preprint on Hugging Face Daily Papers. If you're shipping agents into unfamiliar environments, this is the pre-flight checklist you've been missing.

# Story 4: TRACE
### Landing Page
[excited] TRACE. GUI agents drown in high-res screenshots, and pruning those tokens is irreversible — once discarded, that visual evidence is gone forever.

### Demo
[amazed] TRACE treats pruning as an admission problem: it orders evidence so the tokens worth keeping get in first. Training-free, no fine-tuning, straight latency and memory wins.

### Access
[energetic] Paper and code are linked below. If you're running computer-use agents at scale, this is free performance sitting on the table.
